# stock-market-data

美股可复用 Market Data Plane：负责数据采集、合格性保留、Daily Series、Session Capture、Stage Snapshot、Recovery/Rebase、Probe 与 Inventory。

本仓库只管理市场事实与数据存储，不拥有研究、策略、报告、Evidence、Decision、Evaluation 或 canonical finalization 权威。

> 初始化迁移状态：运行面正在从 `yuatom/stock-dairy` 拆分。第三方 API 数据迁移前，本仓库必须保持 private；当前若仍为 public，不得写入 Twelve Data 等受限数据资产。
